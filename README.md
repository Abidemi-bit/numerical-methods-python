# numerical-methods-python
Numerical Methods for solving PDEs using Python

## Overview
This project implements numerical solutions to partial differential equations
arising in physical systems using finite difference methods.

## Mathematical Background
We consider the one-dimensional heat equation:
∂u/∂t = α ∂²u/∂x²
with appropriate initial and boundary conditions.

## Methods
- Finite Difference Method (FDM)
- Explicit time stepping
- Stability considerations (CFL condition)

## Results
The numerical solution demonstrates diffusion behavior consistent with theory.
Plots illustrate temperature evolution over time.

## Tools
- Python
- NumPy
- Matplotlib

## How to Run
Open the notebook in Jupyter and run all cells.
